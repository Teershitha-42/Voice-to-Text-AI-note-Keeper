# 🎙️ Voice-to-Text AI Note Keeper

An AI-powered voice note keeper that:
- Converts voice into text  
- Automatically summarizes and tags notes  
- Exports notes to PDF  
- Uses React, Node.js, MongoDB, and OpenAI API  

## 🚀 Features
- 🎤 Voice input support  
- ✨ AI-powered summarization  
- 🏷️ Auto-tagging of notes  
- 📄 Export to PDF  

## 🛠️ Tech Stack
- Frontend: React + TailwindCSS  
- Backend: Node.js + Express  
- Database: MongoDB  
- AI: OpenAI API  

## 📦 Installation
```bash
git clone https://github.com/Teershitha-42/Voice-to-Text-AI-note-Keeper.git
